# Playbook de Troubleshooting

O objetivo é registrar um raciocínio técnico reproduzível, e não apenas a solução final.

## 1. Sem internet

1. Confirmar se o problema é de um equipamento ou vários usuários.
2. Verificar cabo/Wi-Fi.
3. Executar `ipconfig`.
4. Testar gateway com `ping`.
5. Testar resolução DNS.
6. Comparar com outro equipamento.
7. Registrar causa raiz e solução no chamado.

## 2. Computador lento

1. Verificar CPU, memória e disco.
2. Conferir processos e inicialização.
3. Verificar espaço disponível.
4. Executar diagnóstico/antivírus conforme política.
5. Reiniciar e validar desempenho.

## 3. Impressora não imprime

1. Confirmar conectividade.
2. Conferir impressora padrão.
3. Verificar fila de impressão.
4. Reiniciar serviço de spooler quando aplicável.
5. Testar página de impressão.

## 4. Falha de acesso

1. Confirmar usuário e sistema afetado.
2. Validar mensagem de erro.
3. Conferir status da conta.
4. Verificar permissões conforme procedimento.
5. Registrar evidências antes de alterar acesso.

## Registro recomendado

- Sintoma
- Impacto
- Evidência coletada
- Hipótese
- Teste executado
- Causa raiz
- Solução aplicada
- Validação final
- Orientação ao usuário
